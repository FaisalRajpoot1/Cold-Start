# Cold Start

**Your onboarding doc is a promise. This is the receipt.**

Cold Start makes IBM Bob 2.0 *actually perform* your project's setup guide — one step per
parallel headless session, each on its own clean clone — then a deterministic check decides
whether each step really worked. You get a runway where every step carries the real money and
minutes it burned, the broken ones are red, and a patch that fixes the document.

Built for the IBM Bob 2.0 Hackathon, 25–27 September 2026.
